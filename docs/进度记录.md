### 防失联规矩（阿什本开发机）

用户原话：「这台不常用，能在这上面开发的都在上面开发，重启也没事，**别让机器失联**。」

- 换内核：用 `grub-reboot` 一次性启动新内核，默认启动项保持旧内核；确认没问题才改默认。
- 动内核前：先让用户在甲骨文控制台确认「串口控制台」能连上、能看到启动过程（ARM 串口是 ttyAMA0）。
- 网络：透明代理/分流规则**只作用于容器网段**（10.88.0.0/16），宿主机自身（SSH、DC）不走代理；改防火墙带自动回滚。
- 资源：每个容器限内存和 CPU（默认 3G / 2 核），同时运行上限 4 台；容器数据定期查磁盘。
- **不动**：SSH、`desktop-commander-remote` 服务、`keepalive`（防甲骨文回收）、甲骨文自带 agent、Komari。
- 每次重启后先确认 DC 重新在线再继续。

## 1. 目标

自己开发「ARM 盒子多开安卓云手机」，对标市面 TK 云手机（MoreLogin、DuoPlus、vcloud 等），**做得比竞品干净**：
- 每台安卓：独立机型档案、独立代理 IP、尽量像真手机。
- 网页管理（像竞品的 `:8099` 后台，但一个页面管所有机器）；**所有参数都映射成数值、可以手动改**。
- 一键新机（重新随机，保留机型）、**一键重置 / 一键刷机**（用户 11-14 新增要求）。
- 最后整合进用户的 **Prism 指纹浏览器**（仓库 `zhangchedan000/fingerprint-browser`，Electron 43 + React 19 + Ant Design 6 + mihomo + PocketBase 团队服务器）。

## 2. 架构原则（用户强调）

> 指纹浏览器的教训：① 先用别人的内核后换官方内核，做了两遍；② 开发时依赖了 Win11，Win10 上缺一堆；③ 没记录，已改过的问题又重做。半个月的活思路顺的话一周能做完。

详见 `架构.md`。要点：通用层/板级层分开；机型相关全写成配置（`profiles/`）；不依赖开发机特殊环境；环境自检；尽早两种环境跑；留接口不提前做功能；一份定义到处引用；**代理缺失或不通 → 禁止开机，绝不走真实网络**。

## 3. 已定的技术方案

| 层 | 方案 |
|---|---|
| 硬件（最终） | **RK3588**（竞品三家全是它）。选板硬条件：**厂家给安卓 SDK 源码（至少 Android 13，最好 14）**、≥16G 内存、M.2 NVMe（或 PCIe 转接）、能装风扇。候选见第 5 节 |
| 开发机 | **甲骨文阿什本 ARM**（无显卡，软件渲染），用官方 Redroid 开发「通用层」；显卡相关等板子 |
| 安卓底子 | 官方 Redroid（开发机）；板子上用「瑞芯微 SDK 的 Mali 驱动 + Redroid 本体」（竞品做法）。安卓版本：先 14，再试 15/16（Treble） |
| 安卓编译 | 第一阶段就要编译一次（改掉 `ro.boot.redroid_*` 暴露参数）。在用户电脑（12900K + 32G + 闲置 1T 固态装 Ubuntu）编译，只编需要的模块 |
| 内核 | 板子用瑞芯微 6.1（或 5.10）；**甲骨文阶段不改内核**，用「挂伪造文件 + seccomp 拦 uname」实现内核版本、CPU 型号伪装；只有 `mrs MIDR_EL1` 指令要改内核（放到后面） |
| 网络 | 宿主机 mihomo 透明代理，按容器固定 IP 分流；UDP/QUIC、IPv6、DNS 都要处理；不用 Redroid 自带代理参数；手机里不出现代理网卡；一号一 IP |
| 机型 | 必须和真实显卡一致：RK3588 = Mali-G610 MP4 → 天玑 7200（显卡核数一致，CPU 布局不同）或 天玑 8100/8200（CPU 4+4 一致，显卡 6 核）机型。美区少见（美国：苹果 67%+，三星、摩托罗拉、Pixel 3%） |
| 管理页 | React 19 + Ant Design 6（主题照搬 Prism，以后直接合进 Prism） |
| 管家程序 | Go，单文件 ARM64，Docker API 管容器，内嵌管理页 |
| 操作通道 | uinput 虚拟触摸屏（不用注入）；打字不装 ADB 键盘；上传视频前清理元数据；群控带随机延迟 |

**路线 B（以后试）**：联发科 Genio 510（Mali-G57 MC2，和三星 Galaxy A15 5G 显卡完全一致）。

## 5. 板子选择（待用户问客服）

| 板子 | 结论 |
|---|---|
| **飞凌 OK3588-C** | 软件最符合：官方 **Android 14 + 内核 6.1.99**，编译手册公开；16G；PCIe3.0×4 插槽（转接卡接 NVMe）；风扇接口。**要 RK3588 不要 RK3588J**（J 版降频）。待问：价格、是否给 A14 SDK |
| **野火鲁班猫 5** | 硬件最符合（M.2 NVMe、风扇、16G）；评论区实拍：**内核 5.10.160**（2025-12 镜像仍是 5.10），有安卓镜像、显卡正常；安卓版本待问 |
| DC-A588 工控盒 | 无 M.2，Android 12，不推荐 |
| 其他 | 友善 NanoPC-T6、Radxa ROCK 5B+、Firefly 只有 Android 12；ROCK 5C 有 Android 14（RK3588S2） |

公开渠道**没有** RK3588 的 Android 15/16 SDK；竞品的 15 是「Mali 驱动 + Redroid 15 本体」。
