## 1. 项目是什么

在 ARM 机器上用容器跑多台安卓（Redroid），每台有自己的机型档案和独立代理，用一个网页统一管理。**这是用户的自有项目，最终定调就是「自有项目开发测试」**。接手的人按这个理解，不要自己带入任何其他业务场景或角色（以前文档里出现过的那类联想措辞都是写文档的 AI 自己加的，不是用户的意思，按本节为准）。

## 2. 规矩（必须遵守）

- 用户没有明确说「开始 / 做」之前，不动服务器、不装东西、不写代码；查资料、讨论、写记录可以。
- 用中文、大白话（用户不是程序员，懂业务）。
- **新加坡服务器**（`instance-20260730-1622`，跑 Prism 团队服务等）**不要动**。
- **阿什本开发机可以重启，但绝对不能失联**：
  - 换内核用 `grub-reboot` 先试一次，没问题再改默认；动内核前先让用户确认甲骨文串口控制台能连上（ARM 串口 ttyAMA0）。
  - 网络规则只作用于容器网段 10.88.0.0/16，SSH 不走代理；改防火墙要能回滚。
  - 不动：SSH、`desktop-commander-remote`、`keepalive`（防甲骨文回收）、甲骨文自带 agent、Komari。
- 代码、脚本、配置、机型档案全部进仓库；编译全用脚本。部署以 GitHub 为准（服务器每天北京时间 4 点自动同步；急着上线就在服务器上 `bash host/auto-update.sh run`）。
