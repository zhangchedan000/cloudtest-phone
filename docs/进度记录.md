## 1. 项目是什么

在 ARM 机器上用容器跑多台安卓（Redroid），每台有自己的机型档案和独立代理，用一个网页统一管理。用户做 TikTok 美区跨境电商，以后作为 Prism 指纹浏览器（`zhangchedan000/fingerprint-browser`）的一个页面接入。

| 阶段 | 状态 |
|---|---|
| 一：甲骨文阿什本开发机（无显卡，软件渲染）上做通用软件层 | ✅ 完成 |
| 二：RK3588 板子（Mali-G610 显卡、硬件视频编码），正式运行环境 | ⏳ 等用户买板子 |

## 2. 规矩（必须遵守）

- 用户没有明确说「开始 / 做」之前，不动服务器、不装东西、不写代码；查资料、讨论、写记录可以。
- 用中文、大白话（用户不是程序员，懂业务）。
- **新加坡服务器**（`instance-20260730-1622`，跑 Prism 团队服务等）**不要动**。
- **阿什本开发机可以重启，但绝对不能失联**：
  - 换内核用 `grub-reboot` 先试一次，没问题再改默认；动内核前先让用户确认甲骨文串口控制台能连上（ARM 串口 ttyAMA0）。
  - 网络规则只作用于容器网段 10.88.0.0/16，SSH 不走代理；改防火墙要能回滚。
  - 不动：SSH、`desktop-commander-remote`、`keepalive`（防甲骨文回收）、甲骨文自带 agent、Komari。
- 代码、脚本、配置、机型档案全部进仓库；编译全用脚本。部署以 GitHub 为准（服务器每 10 分钟自动同步）。
- 踩坑一解决就记 `踩坑记录.md`；状态有变化就更新本文件。
- 主动想坑、联网查坑，先填坑再做。

## 5. 已知限制

- 阿什本没有显卡：软件渲染、软件编码，画面有延迟，高清码率上不去；显卡相关检测一定显示软件渲染。等板子。
- 「直连（仅开发）」走机房 IP，只能开发测试，**开发机不登录真实账号**。
- 国内直连阿什本延迟约 290 ms、带宽几百 Kbit/s：用域名看画面最好让 `*.peachshop.cyou` 走代理，或者切「流畅」。
- Chrome 第一次打开要用户自己点同意条款、选默认浏览器（用户决定不自动设）。
- 剪贴板对话框只做了接口实测，页面按钮没人在浏览器里点过。
- 美国市场基本没有 Mali-G610 机型（机型必须和真实显卡一致这条规矩带来的矛盾）。

## 6. 用户的决定（接手的人不要改）

- **不做谷歌套件**（Play 商店）：先用 Chrome 下载 APK 装 App，真需要再说。
- **不自动把 Chrome 设成默认浏览器**。
- **改内核伪装设备身份**（拦截 `mrs MIDR_EL1`、`uname()` / seccomp）：不做。
- 机型库删了国行 Redmi K50（国行不适合美区）。

## 7. 下一阶段：RK3588 板子

**选板**（下单前问客服：价格、**是否提供 Android 14 SDK 源码**——硬条件）：

| 板子 | 结论 |
|---|---|
| **飞凌 OK3588-C**（首选） | 官方 Android 14 + 内核 6.1.99，编译手册公开；16G；PCIe3.0×4（转接卡接 NVMe）；风扇接口。**要 RK3588 不要 RK3588J**（J 版降频） |
| 野火鲁班猫 5（备选） | 硬件最合适（M.2 NVMe、风扇、16G）；内核 5.10.160；安卓版本待问 |
| 不推荐 | DC-A588 工控盒（无 M.2、Android 12）；友善 NanoPC-T6、Radxa ROCK 5B+、Firefly（只有 Android 12） |

公开渠道没有 RK3588 的 Android 15/16 SDK；竞品的 15 是「Mali 驱动 + Redroid 15 本体」。备选路线：联发科 Genio 510（Mali-G57）。

**板子到手后**：
1. 先用厂家自带系统检查：内核有没有 Redroid 需要的功能（binder / binderfs 等）、Mali 显卡驱动、硬件视频编码能不能被容器用上。
2. 都满足就**不编译内核**，直接装 Docker + 管家程序；缺了就用厂家 SDK 源码打开开关重新编译（只为驱动和 Redroid 功能，每种板子做一次，脚本进仓库）。
3. 管家程序加 `-gpu-family Mali-G610 -gpu-mode host`，实时画面改用硬件编码，测画质和延迟。
4. 一台板子开几台手机：测内存、CPU、温度，定同时运行上限。
5. 部署方式和阿什本一样：`host/setup-host.sh` → `host/install-agent.sh` → 自动同步；网络模块 `host/network.sh install / apply / confirm`。

## 8. 技术方案（已定）

| 层 | 方案 |
|---|---|
| 安卓 | 官方 Redroid 镜像（14、15）；板子上用「瑞芯微 SDK 的 Mali 驱动 + Redroid」 |
| 管家程序 | Go 单文件（ARM64），Docker API 管容器，内嵌管理页（`agent/`） |

| 网络 | 宿主机 mihomo 透明代理，按容器 IP 分流；DNS 也走代理；手机里不出现代理网卡；一号一 IP |
| 机型 | 必须和真实显卡一致（RK3588 = Mali-G610）；档案在 `profiles/` |
| 操作 | 点击滑动用 `input`，中文用剪贴板 + 粘贴键（不装 ADB 键盘）；画面用 screenrecord H.264 |
