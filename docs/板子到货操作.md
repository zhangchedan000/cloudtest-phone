# 魔云腾 Q1 板子到货操作手册（2026-11-17 写、2026-11-18 补刷机/拆机确认，还没在真板子上走过）

给用户看的步骤 + 给接手 AI 看的步骤。资料来源和【确认】/【推断】标注见 `docs/调研/魔云腾适配.md`。

## 〇、要不要拆机？（2026-11-18 查官方 Q1 介绍页确认）

**结论：日常用、刷系统都不用拆机。**

- **刷机键在背面**：Q1 背面接口区有个 MaskROM 键（第 2 项），长按它→断电→再上电就进刷机模式。**不用开盖。**
- **固态（你买的 256G）**：板子标配只有 8GB eMMC，256G 是选配的 M.2 NVMe 固态。你按「32G+256G」整机买的，**固态一般是卖家出厂就装好的**，开箱直接用。盒子里附一把小螺丝刀，官方说明「非特殊要求一般不使用」——那是留给你以后想自己换/加固态时开盖用的。
- **什么时候才要开盖**：只有「固态没装、要自己加」或「以后想换更大固态」时才开盖。开盖就是拧下外壳螺丝、把 M.2 固态斜 30° 插进卡槽、压平拧一颗固定螺丝，附带的螺丝刀就能做。开盖前先断电、摸一下金属机箱放静电。
- 收到货先确认固态在不在：开机登录后看硬盘有没有认到 256G（AI 一条命令就能查）。认到就不用开盖。

## 一、用户要做的（3 步）

1. **插上开机**：网线、12V 电源。**先别刷任何东西**，先看它现在是什么系统。
2. **找 IP**：路由器后台的设备列表里新出现的那个；或者看 Q1 正面小屏。
3. **试着登录**（在自己电脑的终端 / PowerShell 里）：
   - 官方 Ubuntu 固件：`ssh myt@板子IP`，密码 `123456`
   - 魔云腾云手机系统 MYTOS：`ssh user@板子IP`，密码 `myt`；进去后 `su`，root 密码 `myt`
   - 登录成功：把 IP 和用的哪种账号告诉 AI，后面 AI 来做（需要你同意把电脑接到会话里，点一次同意）。
   - 都登录不了：拍屏幕 / 路由器设备列表发给 AI。

## 二、要不要刷系统

| 现在的系统 | 怎么办 |
|---|---|
| 官方 Ubuntu 22.04 | 不刷，直接用 |
| MYTOS（魔云腾自己的云手机系统） | 先试不刷：能 SSH、能切 root、Docker 开着，就直接在上面装管家。装不上再刷官方 Ubuntu |
| 卖家刷过的不明系统 / 进不去 | 刷官方 Ubuntu 22.04 |

- **只刷魔云腾官方给的固件**（官方文档站下载）。不刷 Armbian 等第三方：有用户说 Q1 锁了刷不了，也没人报告在 Q1 上刷成功，刷坏可能变砖或丢显卡驱动（买板子就是为了显卡）。
- **刷机线**（2026-11-18 看官方接口图确认）：Q1 背面的数据口是 **USB-C（Type-C）**，不是 USB-A（之前「公对公」的猜测作废）。刷机线：板子那头 Type-C，电脑那头按电脑接口选——电脑是普通 USB 口就用 **USB-A→Type-C 数据线**（安卓手机那根充电数据线就行，家里基本都有），电脑是 Type-C 口就用 **C→C 数据线**。**唯一要注意：必须是能传数据的线，不是只能充电的线**（只充电的会认不到设备）。一般不用额外买线。备选：官方 Q1 固件页还有「U 盘刷机教程」，支持的话一个普通 U 盘即可。
  - 背面接口（官方图，从左到右）：RJ45 千兆网口、MaskRom 烧录键、USB-C 数据口、两个小孔、DC12V 电源；M.2 NVMe 固态槽在内部。
- 刷机是在 **Windows 电脑**上用瑞芯微官方工具 RKDevTool，不用拆机。官方 Q1 升级教程的步骤（2026-11-18 查到）：
  1. **断电** → **按住背面 MaskRom 键** → **通电** → 用 USB 线把盒子接到电脑；
  2. 装驱动：解压固件包，运行 `刷机驱动\DriverInstall.exe`；
  3. 运行 `RKDevTool.exe` → 点「执行」，等进度条走完。
- **固件只认 Q1 的**：官方最新是 `Q1-0.2.6`（2024-10-24）。官方明确警告「Q1 镜像，C1 不可用，刷错后果自负」。**别刷成 C1 / Q1 Pro 的**（Q1 Pro 的 MaskRom 键在侧面耳机孔里，和 Q1 不一样，说明你买错型号别照搬）。
- 到货后由 AI 先确认当前系统能不能直接用（官方 Ubuntu / MYTOS 能 SSH 就先不刷），确实要刷时 AI 按官方文档把每一步再对着实物讲一遍。

## 三、AI 要做的（大约半天到一天）

在板子上（root，仓库目录）：

1. `bash host/check-board.sh`（只读）+ `bash host/setup-board.sh`（只预检）：内核版本、Mali 显卡驱动和固件、binderfs、PSI、时间命名空间、hwsim、uinput、KRETPROBES、2375 端口。结果写回 `docs/调研/魔云腾适配.md`，把【推断】【未知】逐项改成实测结论。
2. **先挡 2375 端口**（没认证，局域网谁都能控制所有手机）：`setup-board.sh --install` 第一步就做。
3. `bash host/setup-board.sh --install`：setup-host → 拉 cnflysky lineage-20（安卓 13，真 Mali）→ `build-wifi-image.sh` 叠 WiFi / 传感器 / 触摸 / 电话（安卓 13 实测通过）→ 板子参数（Mali-G610、gpu-mode host、超卖 2.5 倍）→ 装管家。
4. `bash host/build-kmod.sh`：pp_uts（uname）、pp_mnt（挂载表）。要厂商内核头文件；pp_mnt 要内核开 KRETPROBES（脚本会检查，没开就跳过）。
5. 开一台手机逐项测：开机、画面（真 GPU 渲染器名字）、硬件编码、点击、WiFi、上网走代理、传感器、电话、check-tells、itest-api。
6. 管理页「服务器」里加这块板子（要 HTTPS 域名或隧道 + 口令，见进度记录多服务器那条）。

**到板子上才知道的**（不行就退回能用的方案，不影响别的）：
- cnflysky 镜像叠我们的层会不会冲突（它 vendor 里有自己的 HAL）；
- `gpu-mode host` 参数对不对、多台手机共用 Mali 的速度；
- WiFi 模拟要的 mac80211_hwsim 模块：内核大概率没有 → 用同版本内核源码编；编不了就走有线（自动退回）；
- 时间命名空间（开机时长归零）、SELinux。

**内存**：Q1 32G，每台按机型 8GB 上限、不超卖只能开 3 台；超卖 2.5 倍约 9 台（开机前还要求实际剩 3GB 以上）。
