# 竞品云手机分析（2026-11-11 / 11-14）

原始数据：`原始数据/CP-2_MoreLogin_2026-11-14.txt`（ADB 读取，1543 行）。DuoPlus 原始数据在用户电脑 `D:\云手机项目\调研\原始数据\DuoPlus_2026-11-11_*.txt`。

## 结论

**三家（vcloud、MoreLogin CP-2、DuoPlus）全是 RK3588 板卡 + 容器 + 改过的安卓**，没有一家是真机。
CP-2 和 DuoPlus 是同一家底层：都是 Redroid（DuoPlus 有 `ro.boot.redroid_gpu_mode`）+ 6.1.118 内核（CP-2 `6.1.118-1.6.3.lxc`、DuoPlus `6.1.118-1.7.0`，同一编译器 clang 12.0.5）。
> 11-11 用浏览器测时曾把 CP-2 误判为「骁龙 8 至尊版真机」，那是浏览器层伪装了 Adreno 830；ADB 读底层是 Mali-G610。

## 三、他们编译了什么

- **内核**：自己编（`work@容器ID`，有版本号持续维护）；uname 改了、/proc/version 没改。
- **安卓**：瑞芯微安卓 SDK + Redroid 容器化 + 自己的伪装（虚拟传感器、虚拟 SIM、虚拟电池、整套机型属性）。

## 四、我们能做得更好的

| 竞品问题 | 我们 |
|---|---|
| 显卡和机型对不上 | 只伪装 Mali-G610 机型 |
| 只改 uname | uname + /proc/version 一起改 |
| CPU 只改 cpuinfo | cpuinfo + midr_el1 + 频率 + mrs 指令 |
| 瑞芯微痕迹 | 全部清掉/改名 |
| 代理网卡暴露 | 代理在宿主机 |
| WiFi 假 | 至少让 App 看到 WiFi；可用 virt_wifi 做真的 |
| 没触摸屏 | uinput 虚拟触摸屏 |
| 传感器乱 | 按机型档案配 |
| 内存 4G、共用 IP | 每台独立 IP |
| 有厂家后台程序 | 系统自己的 |

做不到的（谁都做不到）：显卡只能 Mali-G610（机型选择面窄）；CPU 真实性能；Play Integrity 强完整性；同机共用内核（补丁后只剩理论风险）。用户说不用 GP、不跑分，这些影响小。

**更干净 ≠ 效果一定更好 → 必须实测对照**（我们的、竞品的、真机）。用户真机只有苹果 8 Plus（可做真机组对照）。
