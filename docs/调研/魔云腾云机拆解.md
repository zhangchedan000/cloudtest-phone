# 魔云腾云机拆解（2026-11-24，静态分析，不开机）

板子刷了我们的系统后魔云腾客户端连不上了，它的云机开不了机。用板子上留下的数据做静态分析（只读，没挂载、没动授权，
令牌 / 密钥类字段一律不看不记）：
- `/mmc/containerTemplate/Q1_V3_v1x.json`：它起云机容器的模板（docker create 参数）
- `/mmc/data/<云机>/`：每台云机的 `baseCfg.json`、`cfg.json`、`modelData/`（机型包解开的数据）、`userdata.img`（/data，ext4，debugfs 只读看）

## 容器怎么起
- **非特权容器**（Privileged=false），只加需要的能力（SYS_ADMIN、NET_ADMIN、SYS_MODULE、SYS_PTRACE、MKNOD……），seccomp 不限。
- `/proc/sys`、`/proc/sysrq-trigger`、`/proc/irq`、`/proc/bus`、`/proc/fs` **只读**；`/proc/kcore`、`/proc/timer_list`、`/sys/firmware`…… **屏蔽**。
  → 手机改不了宿主机内核参数（我们是特权容器，靠 hostguard 每 30 秒改回来，#58）。
- 设备直通：每台自己的 binder（/dev/binder1~3 → binder/hwbinder/vndbinder）、`/dev/dri`、`/dev/mali0`、`/dev/mpp_service`（硬件编解码）、
  `/dev/dma_heap/*`、`/dev/ashmem`、`/dev/fuse`、`/dev/input/event0`，以及 **`/dev/tee0`、`/dev/teepriv0`（板子的 TEE 安全芯片）**——
  密钥库可以走真 TEE（我们是软件 keymaster 4.1）。
- `/dev/net/tun` + 宿主网络命名空间（`/proc/1/ns/net` 挂成 /dev/mnetns）：手机里自己的 tun2socks / tun2proxy 走代理。
- 启动参数只有 `androidboot.dobox_tag=<云机名>`，入口 `/init`，端口 5555（ADB）、9082/9083/9086、10000~10008（投屏 / 控制）。

## 每台云机的配置
- **「用过的手机」数据**（baseCfg.json）：附近 WiFi 列表（名字 + BSSID）、通话记录、通讯录、短信历史。
- **标识**（cfg.json 的 overlay，按正则随机）：android_id、序列号、IMEI、WiFi / 蓝牙 / 蜂窝 MAC、蓝牙名、WiFi 名、boot_id、
  **eMMC CID / CSD**（/sys/block/mmcblk0/device/cid）、**MEDIAID**（MediaDrm / Widevine 设备 ID，64 位十六进制）、GFID、RNDID、
  **广告 / 设备 ID：gaid、oaid、vaid、aaid、udid**（谷歌广告 ID、国内 MSA 的 OAID 等）、gnssModel（GNSS 芯片型号串）、ovLibc=1（换真机 libc）。
- 每台单独的 socks5 代理、ADB 端口、分辨率 / dpi / fps、DNS、安全补丁日期覆盖。
- `fakePackage` / `packageRandom` / `randomFile`：应用包名随机化、随机文件（防同一批机器被关联）。

## modelData（机型包解开后实际用到的）
cpu/（整个 /sys/devices/system/cpu）、cpuinfo、meminfo、mountinfo、mountstats、df.output、**libc.so（真机的）**、**auxv、vdso_data（真机的）**、
camera.json、telephone.json、**location.json（基站：MCC/MNC/LAC/CID、经纬度）**、libraries.txt、**systemLib.json（真机 125 个系统共享库名，
PackageManager 报的）**、adb_debug.prop（属性）、**pif.json（Play Integrity：拿一台过认证的真机指纹）**、**hides.json（要对 App 隐藏的文件）**。

## /data 里看到的
- `/data/system/pif.json`：Play Integrity 伪装（和社区 PlayIntegrityFix 同款字段：BRAND / DEVICE / FINGERPRINT / SECURITY_PATCH……）。
- `/data/local/tmp`：rpa.apk、libwebrtc / libjingle（投屏、自动化）。
- hides.json 列的是它自己的东西（23 个）：sdsh、rfsd、wr（投屏）、sd、**fkcam（假摄像头服务）**、hwcodec、tun2socks / tun2proxy、
  extservice2、bootinit2、各自的 .rc，和 `wuying_overlay_frameworks_base_core.apk`（框架资源覆盖包，名字像阿里「无影」云手机）。
  → 它有一套「隐藏自己文件」的机制，App 查不到这些。

## 和我们对照（结论见 进度记录 / 对话）
它有、我们没有：用过的手机数据、eMMC ID、MediaDrm ID、广告 / OAID、Play Integrity、系统共享库名、基站信息、真机 libc / auxv / vdso、
TEE 密钥库、非特权容器、隐藏自己的文件。
我们有、它（从数据看）没有或不确定：手机里真 SELinux 强制模式、显卡名转接（伪装档）、传感器数据按地区 / 时间生成、IMEI 型号码按真机库、
系统特性按真机、摄像头参数按真机生成。
